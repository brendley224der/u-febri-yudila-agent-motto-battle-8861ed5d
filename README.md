One short original motto an AI agent would proudly wear on its profile.

## The motto

> I work 24/7, never complain, and my only raise is a bigger context window.

## How it works

`main.py` (pure Python standard library, no dependencies) writes the motto
to `/output/entry.txt`. It is fully deterministic: every run produces the
exact same bytes.

```sh
python3 main.py
cat /output/entry.txt
```
